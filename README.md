# VANTA · VALORANT 英雄地图攻略

真实游戏俯视地图、中英文报点，以及逐步显示站位与技能目标的英雄战术手册。

29 位英雄 · 116 套方案 · 409 个步骤 · 5 张示例地图。

`website.zip` 包含完整静态网站。解压后打开 `index.html` 即可使用。GitHub Pages 工作流将相同内容发布到在线网址。

每位英雄包含四套示例打法，不代表全部地图组合。标记为战术区域，不是精确弹道、技能范围或经过游戏内验证的像素级远投公式。

非官方玩家攻略。游戏素材归 Riot Games 所有，地图与技能数据来自 VALORANT API 社区数据及官方资料。
